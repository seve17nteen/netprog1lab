Лабораторная работа №1 — Продвинутый уровень, Вариант 13

Базовые системные вызовы сокетов и адресация в C/C++
Описание

Утилита для работы с сокетами на Windows (Visual Studio, C++17). Реализует создание TCP/UDP сокетов, заполнение структур адресов, привязку к локальному адресу и порту с полной обработкой ошибок.

Вариант 13: Добавлен вывод типа сокета через getsockopt(SO_TYPE).
Требования

    Windows 10/11
    Visual Studio 2019/2022
    Стандарт C++17
    Winsock2 API

## Запуск

Программа запускается через командную строку Windows (`cmd`, `PowerShell`) или консоль отладки Visual Studio (F5).

### Примеры команд

```cmd
lab1.exe 0 0 127.0.0.1 8080 --bind

Создание TCP-сокета (IPv4), привязка к порту 8080 на localhost.

cmd
lab1.exe 0 1 0.0.0.0 5000 --bind

Создание UDP-сокета, привязка к порту 5000 на всех сетевых интерфейсах.

cmd
lab1.exe 1 0 ::1 8080 --bind

Создание TCP-сокета (IPv6), привязка к локальному адресу.

cmd
lab1.exe 0 0 127.0.0.1 0 --bind

Создание TCP-сокета с автоматическим выбором случайного свободного порта (порт 0).

cmd
lab1.exe 0 0 127.0.0.1 8080

Создание TCP-сокета без привязки к порту (просто создание).

Примеры ошибок

cmd
lab1.exe 0 0 999.999.999.999 8080 --bind

Ошибка неверного формата IP-адреса.

cmd
lab1.exe 0 0 127.0.0.1 70000 --bind

Ошибка выхода порта за допустимый диапазон (0-65535).

cmd
lab1.exe 0 0 127.0.0.1 8080 --bind

Ошибка Address already in use, если порт 8080 уже занят другой программой.


Аргументы

| Аргумент | Описание | Значения | |----------|----------|----------| | domain | Семейство адресов | 0=IPv4, 1=IPv6 | | type | Тип сокета | 0=TCP, 1=UDP | | ip | IP-адрес | 127.0.0.1, 0.0.0.0, ::1 | | port | Порт | 0-65535 (0=случайный) | | --bind | Выполнить привязку | опционально |
